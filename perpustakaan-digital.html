Belum ada data buku. Gunakan tab ➕ Tambah Buku untuk menambahkan koleksi baru.

📗 Tambah Koleksi Buku Baru

Isi form di bawah untuk menambahkan buku ke inventaris perpustakaan. Data disimpan otomatis di browser (localStorage) dan bisa diekspor ke CSV/Google Sheet.

Berapa buku fisik yang tersedia
URL gambar cover (Google Drive, GitHub, dll.)
URL file PDF atau e-book digital

📤 Ekspor Data Koleksi Buku

Download data dalam format CSV untuk diunggah ke Google Sheet, agar terhubung dengan katalog publik.

Cara menghubungkan ke Google Sheet:
1. Klik tombol Download CSV di bawah
2. Buka Google Sheets → menu Data → Import data
3. Upload file CSV yang sudah di-download
4. Publish sheet → salin URL → update SHEET_CSV_URL di kode ini jika ingin katalog publik sinkron
