📤 Ekspor Data Koleksi Buku

Download data dalam format CSV untuk diunggah ke Google Sheet (untuk terhubung ke perpustakaan-digital.html).

Cara menghubungkan ke Google Sheet:
1. Klik tombol Download CSV di bawah
2. Buka Google Sheets → Data → Import data
3. Upload file CSV yang sudah di-download
4. Publish sheet → salin URL → ganti SHEET_CSV_URL di perpustakaan-digital.html
